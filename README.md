📊 Customer Shopping Behavior Analysis
🔍 Overview

This project focuses on analyzing customer shopping behavior using a combination of Python, SQL, and Power BI. The goal is to extract meaningful insights from transactional data, understand customer patterns, and support data-driven business decisions.

📁 Dataset
Contains customer purchase transactions
Includes features like:
Customer demographics (Age, Gender, Location)
Purchase details (Product, Category, Amount, Season)
Behavioral data (Frequency, Discounts, Ratings, Subscription status)
Data was cleaned and prepared before analysis
🛠️ Tools & Technologies
Python (Pandas, NumPy) – Data loading, cleaning, EDA
SQL (PostgreSQL/MySQL/SQL Server) – Data analysis & querying
Power BI – Interactive dashboard creation
Gamma – Presentation (PPT) generation
Excel/CSV – Dataset source
⚙️ Project Steps
1. Data Loading & Cleaning (Python)
Imported dataset using Pandas
Handled missing values
Standardized column names
Created new features (e.g., age groups, purchase frequency)
2. Exploratory Data Analysis (EDA)
Analyzed customer demographics
Identified spending patterns
Explored relationships between variables
Generated summary statistics
3. SQL Analysis
Loaded cleaned data into database
Wrote queries to answer business questions:
Revenue by customer segments
Top-selling products
Subscription vs non-subscription behavior
Discount impact on sales
4. Dashboard Creation (Power BI)
Built interactive visualizations
Included KPIs, charts, and filters
Enabled easy exploration of insights
5. Reporting & Presentation
Created a structured project report
Designed PPT using Gamma for presentation
📊 Dashboard

The Power BI dashboard provides:

Customer segmentation insights
Revenue analysis by category and demographics
Product performance overview
Interactive filters for dynamic analysis
📈 Results & Insights
Identified high-value customer segments
Found top-performing products and categories
Analyzed impact of discounts on revenue
Observed patterns in subscription-based customers
Provided actionable business recommendations
